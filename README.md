# SpaceShooter

SpaceShooter is a 2D space shooter made with Godot (C# + GDScript assets).

![Gameplay screenshot](docs/screenshot.png)

## About

This repository contains the game's scenes, scripts and assets. Prebuilt binaries for Linux and Windows are in the `Game/` folder; publish those as GitHub Releases rather than committing large binaries to the repository.

## Contents

- `scenes/` — Godot scene files (.tscn)
- `scripts/` — C# and GDScript game logic
- `audio/`, `Ui/`, `SpaceShip Game Assets/` — assets used by the game
- `Game/` — platform builds (Linux/Windows) (keep these out of version control; use Releases)

## Controls

- Move: arrow keys / WASD
- Shoot: `Space`
- Pause: `Esc`
- Ability; `Shift`
## Running (development)

1. Install Godot (the editor used to author the project).
2. Open `project.godot` in the Godot editor.
3. Run the project from the editor.
